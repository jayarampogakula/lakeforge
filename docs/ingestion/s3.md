# AWS S3 Ingestion Guide

Load files from Amazon S3 buckets into your Data Lakehouse.

## Overview

* Load various file formats (Parquet, CSV, JSON, Avro, ORC)
* Auto Loader for incremental ingestion
* IAM role or access key authentication
* Supports S3, S3A, and S3N protocols

## Prerequisites

* S3 bucket access
* IAM role or AWS credentials
* Appropriate S3 permissions (s3:GetObject, s3:ListBucket)

## Configuration

### Basic File Load

```python
from lakeforge.ingestion import S3Loader

spark = SparkSession.builder.appName("S3Ingestion").getOrCreate()

# Using IAM role (recommended)
loader = S3Loader(spark=spark)

# Load Parquet files
df = loader.load(
    path="s3://my-bucket/data/orders/",
    file_format="parquet"
)

# Write to Bronze
df.write.format("delta").mode("overwrite").save("/mnt/bronze/s3_orders")
```

### With Access Keys

```python
loader = S3Loader(
    spark=spark,
    aws_access_key=dbutils.secrets.get(scope="aws", key="access-key"),
    aws_secret_key=dbutils.secrets.get(scope="aws", key="secret-key")
)
```

### Load CSV

```python
df = loader.load_csv(
    path="s3://my-bucket/data/customers.csv",
    header=True,
    infer_schema=True,
    delimiter=","
)
```

### Load JSON

```python
df = loader.load_json(
    path="s3://my-bucket/data/events/*.json",
    multiline=True
)
```

### Auto Loader (Incremental)

```python
stream_df = loader.load_with_autoloader(
    source_path="s3://my-bucket/incoming/",
    file_format="json",
    schema_location="/mnt/schemas/incoming"
)

# Write to Bronze
query = stream_df.writeStream \
    .format("delta") \
    .outputMode("append") \
    .option("checkpointLocation", "/mnt/checkpoints/s3_incoming") \
    .start("/mnt/bronze/incoming")
```

## IAM Policy Example

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "s3:GetObject",
        "s3:ListBucket"
      ],
      "Resource": [
        "arn:aws:s3:::my-bucket",
        "arn:aws:s3:::my-bucket/*"
      ]
    }
  ]
}
```

## Best Practices

* Use IAM roles instead of access keys
* Enable S3 event notifications for Auto Loader
* Partition data by date in S3
* Use columnar formats (Parquet, ORC) for analytics
* Implement lifecycle policies for data retention
