Complete Repository File Map & Roles

Every file in LakeForge has a dedicated single responsibility. The table below lists all core files across the repository, explaining exactly what they do, when they run, and how they interact:

Directory / File Path Component Type Role & Execution Lifecycle
lakeforge/bronze/bronze_writer.py Core Writer Writes raw data to Delta Bronze tables with audit columns (_ingestion_timestamp, _record_hash), file tracking, and enforces schema drift policies (allow, strict, quarantine).
lakeforge/silver/transformer.py Core Transformer Declarative transformation orchestrator. Applies casting, standardization, regex replacement, deduplication, derived columns, joins, and explicit DDL schema casting in the Silver layer.
lakeforge/silver/scd_type2.py SCD-2 Handler Maintains historical change records in Silver dimensions via Delta MERGE with effective dates, expiration timestamps, and active flags.
lakeforge/silver/deduplication.py Deduplicator Deduplicates DataFrames across business keys with tie-breaking order (e.g. latest timestamp wins).
lakeforge/silver/merge_engine.py Merge Engine Generic Delta Lake upsert engine. Matches on composite primary keys and executes whenMatchedUpdateAll() and whenNotMatchedInsertAll().
lakeforge/gold/aggregations.py Gold Aggregator Computes business KPI metrics, dimensional rollups, multi-table joins, and window analytics for Gold data marts.
lakeforge/views/view_manager.py View Manager Generates on-demand Unity Catalog or temporary views for reporting without having to re-run heavy ETL transformations.
lakeforge/governance/governance_engine.py Governance Engine Centralized Unity Catalog reconciler. Parses access_control.json to generate RBAC grants, dynamic PII column masks, and row-level filter functions.
lakeforge/maintenance/table_maintenance.py Maintenance Suite Delta maintenance manager. Automates OPTIMIZE (with Z-ORDER clustering), VACUUM file retention purging, and ANALYZE TABLE CBO statistics.
lakeforge/dq/dq_engine.py Data Quality Validates DataFrames against business rules (null checks, regex, ranges, allowed values, cross-platform datatypes) and isolates bad records into quarantine.
lakeforge/ingestion/universal_loader.py Universal Loader Dispatches file reading across CSV, Excel, JSON, Parquet, Avro, ORC, XML, Delta, and Fixed-Width Text with schema auto-inference.
lakeforge/metadata/config_parser.py Config Parser Parses and merges all JSON configs. Resolves multi-tenant client inheritance (client_id) and environment stages (dev, test, staging, prod).
lakeforge/observability/metrics.py Audit Ledger Records run-level operational statistics (rows read, rows written, duration, status) into an append-only Delta audit ledger.
lakeforge/observability/alerts.py Alert Dispatcher Formats and sends alert webhooks to Slack or Microsoft Teams upon pipeline errors or severe DQ threshold breaches.
lakeforge/observability/lineage.py Lineage Tracker Tracks upstream source files, intermediary tables, and downstream target marts to ensure full data provenance.
lakeforge/cli/run_pipeline.py CLI Dispatched Dispatches pipeline execution from terminal: --layer bronze|silver|gold|views|governance|maintenance.
lakeforge/cli/deploy.py CLI Deployer Stages and deploys LakeForge metadata configs, notebooks, and Asset Bundles to target Databricks workspaces.
lakeforge/cli/validate_config.py CLI Validator Zero-Spark schema validator. Validates all JSON configs locally in CI/CD before any code is deployed to cloud environments.
lakeforge/cli/init_project.py CLI Scaffolder Initializes a new LakeForge project folder with directory skeletons and starter configuration templates.
pipelines/*.ipynb (6 notebooks) Databricks Notebooks Parameterized, metadata-driven orchestration notebooks for Bronze Ingestion, Silver Transformation, Gold Aggregations, Views Creation, Governance Reconciliation, and Table Maintenance.
azure-pipelines.yml Azure DevOps Multi-stage CI/CD pipeline for Azure DevOps. Executes test validation and automated deployment to dev, test, staging, or prod.
.github/workflows/ci_cd.yml GitHub Actions Multi-stage CI/CD workflow for GitHub Actions with manual workflow_dispatch stage deployment.
databricks.yml & lakeforge_bundle.yml Asset Bundle (DAB) Defines Databricks Asset Bundle specifications, job schedules, compute clusters, and multi-environment targets.
deployment/terraform/ Terraform IaC Provisions Unity Catalog catalogs, schemas, volumes, and storage credentials across stages (dev.tfvars, test.tfvars, etc.).
tests/unit_tests/*.py Unit Tests Automated PyTest suite covering 54 test assertions across all layers, multi-tenancy, drift policies, and table maintenance.

1. Bronze Layer (lakeforge.bronze.bronze_writer)

Class BronzeWriter(spark: SparkSession)

Returns BronzeWriter

Instantiates the Bronze Writer engine responsible for appending or merging raw records into Delta Lake tables, maintaining file trackers, and evaluating schema drift.

add_audit_columns

add_audit_columns(df: DataFrame, add_hash_key: bool = True, hash_columns: Optional[List[str]] = None, add_ingestion_timestamp: bool = True, add_ingestion_date: bool = True, add_source_system: bool = True, source_system: str = "unknown") -> DataFrame

Enriches an incoming raw DataFrame with standardized operational audit columns before saving to Delta Lake.

ParameterTypeDefaultDescription
dfDataFrameRequiredInput raw PySpark DataFrame.
add_hash_keyboolTrueGenerates an MD5 _record_hash column over specified or all non-audit columns for deduplication.
hash_columnsList[str]NoneSpecific column names to hash. If None, all non-underscore columns are used.
add_ingestion_timestampboolTrueAdds _ingestion_timestamp (Spark current_timestamp()).
add_ingestion_dateboolTrueAdds _ingestion_date (Spark to_date(current_timestamp())).
add_source_systemboolTrueAdds _source_system string literal.

write_to_bronze

write_to_bronze(df: DataFrame, target_table: str, catalog: str, schema: str, mode: str = "append", partition_by: Optional[List[str]] = None, add_audit_columns: bool = True, source_system: str = "unknown", merge_keys: Optional[List[str]] = None, optimize_after_write: bool = False, z_order_by: Optional[List[str]] = None, schema_evolution: str = "allow") -> Dict[str, Any]

Writes data to a Delta Lake table with schema drift detection and optional in-line optimization.

ParameterTypeDefaultDescription
target_tablestrRequiredTarget table name without catalog/schema prefix.
catalogstrRequiredTarget catalog name (e.g. lakeforge_dev).
schemastrRequiredTarget schema name (e.g. bronze).
modestr"append"Write mode: "append", "overwrite", or "merge".
schema_evolutionstr"allow"Policy: "allow" (merges schema), "strict" (raises SchemaDriftError if unexpected columns appear), "quarantine" (diverts drifted rows to <table>_quarantine).

3. Centralized Governance & Security (lakeforge.governance.governance_engine)

Class GovernanceEngine(spark: Optional[SparkSession] = None)

Governance Engine

Centralizes all Unity Catalog permission enforcement, SQL GRANT generation, PII column masking, and row-level filtering.

load_governance_config

load_governance_config(config_path_or_dir: str, client_id: Optional[str] = None, environment: Optional[str] = None) -> AccessControlConfig

Parses access_control.json, resolves {catalog} tokens against stage settings, and merges client-specific tenant overrides.

generate_masking_ddl

generate_masking_ddl(config: AccessControlConfig) -> List[str]

Generates Databricks SQL DDL statements for creating dynamic PII masking functions and applying them to table columns:

CREATE OR REPLACE FUNCTION lakeforge_dev.silver.mask_email(email STRING) RETURNS STRING RETURN CASE WHEN is_account_group_member('pii_admins') THEN email ELSE concat(substring(email, 1, 2), '****@****.com') END
ALTER TABLE lakeforge_dev.silver.customers_clean ALTER COLUMN email SET MASK lakeforge_dev.silver.mask_email

generate_row_filter_ddl

generate_row_filter_ddl(config: AccessControlConfig) -> List[str]

Generates Databricks SQL DDL statements for creating row-level security functions and binding them to tables:

CREATE OR REPLACE FUNCTION lakeforge_dev.silver.filter_customers_by_region(region STRING) RETURNS BOOLEAN RETURN is_account_group_member('global_data_access') OR region = current_user()
ALTER TABLE lakeforge_dev.silver.customers_clean SET ROW FILTER lakeforge_dev.silver.filter_customers_by_region ON (region)

reconcile_permissions

reconcile_permissions(config_path_or_dir: str, environment: str = "dev", dry_run: bool = False, target_catalog: Optional[str] = None, client_id: Optional[str] = None) -> Dict[str, Any]

Reconciles all grants, masking functions, and row filters. In dry_run=True mode, it audits and returns the statements without applying them.

4. Table Maintenance Suite (lakeforge.maintenance.table_maintenance)

Class TableMaintenanceManager(spark: Optional[SparkSession] = None)

Maintenance Manager

Automates compaction, clustering, stale log purging, and Cost-Based Optimizer (CBO) statistics computation across Delta tables.

optimize_table

optimize_table(table_name: str, zorder_by: Optional[List[str]] = None, where_clause: Optional[str] = None, dry_run: bool = False) -> Dict[str, Any]

Executes OPTIMIZE <table> [WHERE <clause>] [ZORDER BY (<columns>)] to compact small files and co-locate data by business keys.

vacuum_table

vacuum_table(table_name: str, retain_hours: int = 168, dry_run: bool = False) -> Dict[str, Any]

Executes VACUUM <table> RETAIN <hours> HOURS [DRY RUN] to purge unreferenced data files older than retention policy (default: 168 hours / 7 days).

analyze_table

analyze_table(table_name: str, columns: Optional[List[str]] = None, dry_run: bool = False) -> Dict[str, Any]

Executes ANALYZE TABLE <table> COMPUTE STATISTICS [FOR COLUMNS ...] to refresh table statistics for the Spark Catalyst query optimizer.

run_layer_maintenance

run_layer_maintenance(config_dir: str, stage: str = "dev", layer: str = "all", client_id: Optional[str] = None, vacuum_retain_hours: int = 168, dry_run: bool = False) -> Dict[str, Any]

Discovers all tables defined in configurations for Bronze, Silver, and Gold layers and performs maintenance on all of them in a single batch.

5. Data Quality Engine (lakeforge.dq.dq_engine)

Class DQEngine(spark: SparkSession)

Data Quality Engine

Validates raw DataFrames against declarative rules, computes error counts, and splits data into clean records vs quarantined records.

validate_dataframe

validate_dataframe(df: DataFrame, rules: List[Dict[str, Any]]) -> Dict[str, Any]

Executes all validation rules against a DataFrame and returns a comprehensive validation summary dictionary containing:

  • valid_df: DataFrame containing only records that passed all critical rules.
  • quarantine_df: DataFrame containing rejected records with error tags.
  • rules_executed: Total rule count.
  • rules_passed: Count of rules with 0 violations.
  • quarantine_count: Total row count routed to quarantine.

Individual Rule Methods

MethodParametersVerification Logic
run_null_checkdf, column, threshold=0.0Fails if null percentage in column exceeds threshold.
run_duplicate_checkdf, columnsDetects duplicate primary or composite keys.
run_range_checkdf, column, min_value, max_valueVerifies numeric or date values stay within boundaries.
run_regex_checkdf, column, patternValidates email, phone, or postal codes using regular expressions.
run_allowed_values_checkdf, column, allowed_valuesEnsures categorical column values belong to a defined whitelist.
run_datatype_checkdf, column, expected_typeCross-platform type family validation (e.g. integer matches int, bigint, long).

    "staging": {

    "prod": {

2. Bronze Ingestion Configuration (configs/ingestion/*.json)

Specifies how raw landing files are ingested into Bronze Delta tables:

ingestion/transactions.json
{
  "source_name": "transactions",
  "source_type": "csv",
  "file_path": "/mnt/lake/landing/transactions/*.csv",
  "target_catalog": "lakeforge_dev",
  "target_schema": "bronze",
  "bronze_table": "transactions",
  "silver_table": "transactions_clean",
  "schema_evolution": "strict",     // "allow" | "strict" | "quarantine"
  "business_key": ["transaction_id"],
  "merge_strategy": "upsert",       // "append" | "overwrite" | "upsert"
  "options": {
    "header": "true",
    "inferSchema": "true",
    "delimiter": ","
  }
}

Specifies column casting, cleansing, standardization, and deduplication:

  "transformations": [
    {
      "type": "standardize",
      "columns": ["first_name", "last_name"],

    {

      "columns": ["email"],
      "case": "lower"
    },

    },
    {
      "type": "deduplicate",

      "order": "desc"

  ]

5. Unity Catalog Governance (configs/governance/access_control.json)

Centralized RBAC, PII column masking, and row-level filters with {catalog} templating:

governance/access_control.json
{
  "roles": {
    "business_analysts": {
      "principals": ["analysts_group"],
      "catalogs": { "{catalog}": ["USE CATALOG"] },
      "schemas": { "{catalog}.silver": ["USE SCHEMA"] },
      "tables": { "{catalog}.silver.customers_clean": ["SELECT"] }
    }
  },
  "masking_functions": [
    {
      "name": "mask_email",
      "schema": "silver",
      "input_column": "email",
      "expression": "CASE WHEN is_account_group_member('pii_admins') THEN email ELSE concat(substring(email, 1, 2), '****@****.com') END"
    }
  ],
  "column_masks": [
    {
      "table": "{catalog}.silver.customers_clean",
      "column": "email",
      "function": "{catalog}.silver.mask_email"
    }
  ],
  "row_filters": [
    {
      "name": "filter_by_region",
      "schema": "silver",
      "table": "{catalog}.silver.customers_clean",
      "filter_columns": ["region"],
      "expression": "is_account_group_member('global_data_access') OR region = current_user()"
    }
  ]
}
