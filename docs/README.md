# LakeForge Documentation Portal

Welcome to the **LakeForge Documentation Portal**.

👉 **Open [`docs/index.html`](index.html) in your browser** to explore the interactive documentation portal featuring:
- 🎨 Modern developer portal UI with dark / light mode toggle
- 🔍 Live interactive search and navigation
- 📋 One-click copyable code snippets for CLI, Python SDK, JSON configs, and SQL
- 🏗️ End-to-end Medallion Architecture walkthrough (Bronze, Silver, Gold, Views)
- 🏢 Multi-Tenant Client Scoping (`client_id`)
- 🛡️ Centralized Unity Catalog RBAC, PII Masking, and Row-Level Filters
- ⚡ Automated Delta Table Maintenance (`OPTIMIZE`, `Z-ORDER`, `VACUUM`, `ANALYZE`)
- 🚀 Multi-Stage CI/CD with Azure DevOps (`azure-pipelines.yml`) & GitHub Actions
